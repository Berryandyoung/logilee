Global Trade Explorer

Search annual UN Comtrade HS data by reporter, partner, HS code, year, and flow. The dashboard shows bilateral trade value, exports versus imports, YoY movement, a recent trend, detailed rows, and source/classification notes.

Choose a reporter, partner, HS code, year, and flow, then run a UN Comtrade query.

Data scope

This tool uses UN Comtrade annual commodities data for HS-based bilateral trade screening. Values are shown in USD, with raw values available in Detailed Data.

HS descriptions use the UN Comtrade HS combined reference. HS combined data can include reported or converted classifications, so confirm HS definitions and source records before customs filing, audit work, or binding classification decisions.
