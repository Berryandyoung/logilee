Complete Guide to CBM Calculation

A practical guide to the CBM formula, mixed-package totals, quote preparation, common errors, and calculation limits.

2025-05-114 min readShare

When is CBM useful?

CBM, or cubic metre, expresses the volume occupied by cargo. It gives shippers and forwarders a common unit for quote requests, LCL-versus-FCL comparisons, and warehouse, vehicle, or container planning.

The basic formula

When dimensions are in centimetres, calculate one package as length × width × height ÷ 1,000,000. When dimensions are already in metres, multiply the three values directly. For identical packages, multiply the result by the quantity.

Worked example

One carton measuring 120cm × 80cm × 100cm is 0.96 CBM. Five identical cartons total 4.80 CBM. If a shipment contains different package sizes, calculate each size separately and add the results.

Checklist before requesting a quote

  1. Measure the outside dimensions after packing, using one consistent unit.
  2. Separate packages by size and record the quantity of each.
  3. Calculate each group and add the CBM totals.
  4. Record gross weight, packaging type, and any loading restrictions.
  5. Send CBM, weight, quantity, origin, destination, and timing to the forwarder.

Common mistakes

  • Mixing millimetres, centimetres, metres, or inches without conversion.
  • Using product dimensions while omitting pallets or outer packaging.
  • Forgetting quantity or combining unlike package sizes in one calculation.
  • Assuming CBM alone determines the final freight charge or loading feasibility.

What CBM does not tell you

CBM is a planning value, not a final freight quotation. Airfreight volumetric weight, LCL minimum charges, container internal dimensions and weight limits, package shape, and loading orientation can all affect the result. Confirm the applicable charging and loading rules with the forwarder or carrier.
