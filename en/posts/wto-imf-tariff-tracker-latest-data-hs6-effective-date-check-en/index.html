WTO-IMF Tariff Tracker Releases Latest Data for HS 6-Digit and Effective-Date Checks

The WTO released the latest WTO-IMF Tariff Tracker data on September 9, 2026.

2026-09-15 2 min read Share

The WTO released the latest WTO-IMF Tariff Tracker data on September 9, 2026. Businesses can use the data to recheck recent tariff changes in key markets and applicable rates by trading partner, using HS 6-digit codes and effective dates.

Key developments

The WTO released the latest WTO-IMF Tariff Tracker data on September 9, 2026. The data allows businesses to review tariff changes by HS 6-digit code and effective date.

What changed

Businesses can use the updated tracker to recheck recent tariff changes in key markets and the applicable rate for each trading partner. The supplied information does not identify specific products or countries whose tariffs changed, or quantify any changes.

Who should review the data

Exporters and importers trading with major markets should prioritize a review. The relevant checks are the product’s HS 6-digit classification and the rate applicable to the trading partner. These details can support renewed reviews of pricing, costs and customs-related planning.

Timing for operational checks

The latest data was released on September 9, 2026. For upcoming transactions, businesses should review both the HS 6-digit code and the tariff’s effective date. The available source does not establish the start date of any particular tariff change, so the effective-date field should be checked against the planned transaction and customs timeline.

Practical checklist

  • Confirm that each product’s HS 6-digit code matches internal product and customs records.
  • Check for recent tariff changes in the key markets served by the business.
  • Recheck the rate applicable to each trading partner.
  • Compare the effective date with the planned transaction date and customs schedule.
  • If the product classification or country-specific result is unclear, do not treat the tracker alone as a final determination; flag it for further review.

What businesses should do next

The data release provides a way to review tariff changes by HS 6-digit code and effective date; it does not, based on the supplied information, provide a single blanket tariff change for all businesses. Companies can apply it by listing their main products and markets, then comparing each product’s applicable rate and effective date with existing internal records.

The supplied material does not include country- or product-specific tariff changes, the size of any change, additional regulations or customs procedures. Those points require separate review against the relevant transaction details.

*Data reference: information released on September 9, 2026*
